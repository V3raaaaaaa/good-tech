# Affiliate kode-saja, komisi order pertama, tier

## Ringkas
Tiap affiliate dapat satu kode diskon unik. Atribusi cuma lewat kode di checkout (gak ada link/cookie). Komisi 12% dari order pertama trader itu, naik ke 15% di 40 referral dan 18% di 150. Pembeli dapat diskon 5%; komisi dihitung dari harga sebelum diskon.

## Kenapa bagus
- Atribusi kode = deterministik. Gak ada sengketa cookie, gak ada "last click".
- Komisi cuma order pertama → gak ada insentif muter order kecil berulang.
- Hold 5 hari + minimum $100 + KYC/KYB sebelum payout pertama nutup self-referral dan refund-farming.
- Aplikasi di-review manual; email aplikasi harus sama dengan akun.

## Cara kerja
- Aturan larangan: gak boleh bid brand di paid search, gak boleh ngaku resmi, gak boleh klaim income atau pakai screenshot payout orang lain, gak boleh pakai kode sendiri.
- Komisi dibayar crypto.

## Cara pakai di project gw
- Referral mint/launch: kode di checkout, komisi dari transaksi pertama saja, hold beberapa hari sebelum bisa ditarik.
- Tier berdasarkan jumlah referral unik, bukan volume.

## Caveat / jangan ditiru
- Status "claimed": angkanya dari help center, gak diuji.
- Tanpa link tracking, affiliate kehilangan atribusi kalau pembeli lupa masukin kode. Buat audiens non-teknis itu bocor.

## Bukti
- Help center: "12% of the first order … 15% at 40 referred traders and 18% at 150", "available 5 days after the purchase … $100 minimum", "affiliate links and cookie-based tracking are not currently part of the program".
